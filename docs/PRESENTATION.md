# Remote presentation plan
The organizer allocates 30 minutes. Confirm whether this includes questions; this plan reserves ten minutes for discussion.

| Minutes | Content |
| --- | --- |
| 0–3 | Coordination problem and bathroom-change scenario |
| 3–5 | Scope, stakeholders and responsibility model |
| 5–12 | Live change, impact explanation, review and client decision |
| 12–16 | Architecture, guest isolation and dependency traversal |
| 16–18 | Design tradeoffs, testing and current limitations |
| 18–20 | AI assistance and next development priorities |
| 20–30 | Questions and deeper workflow demonstrations |

Be ready to explain why approval does not complete prerequisites, how cycles are rejected, why explicit dependencies were chosen, and how stale writes are handled. Clearly distinguish demo role switching from actual account permissions. Keep the recorded walkthrough available as a fallback if the live connection fails.
